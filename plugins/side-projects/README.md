# side-projects

Matt's personal claude.ai skills for his side projects, kept here so they load
in every repo and in the GitHub Action:

- `new-project`: interactive quick start from idea to wired-up repo (GitHub,
  Vercel, Supabase, Spaceship domain and Spacemail, Boards, portfolio).
- `portfolio-tool`: house recipe for tools served under `mattblack.space/tools/<slug>/`.
- `project-tickets`: GitHub Issues as tickets and `docs/*.md`, as shown at mattblack.space/boards.

The one change from the claude.ai copies: `new-project` step 4 now defers to the
`repo-setup` skill for the per-repo baseline instead of listing it.
